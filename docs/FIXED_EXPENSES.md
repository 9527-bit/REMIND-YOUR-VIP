# 固定支出：话费、宽带与房租

[返回首页](../README.md)

固定支出适合每月持续发生的费用。录入一次，后台按账单日逐月生成记录；默认静默，仍计入月均和年度预算。

## 添加每月 58 元话费

1. 点击“添加订阅”，将“记录类型”选为“固定支出”，可直接使用“手机话费”模板。
2. 输入原币费用 58，默认人民币。将“本期账单日”填为本月实际账单日，例如每月 1 日扣费，当前账期填 2026-11-01；下次账单日会按月计算。
3. 保持“持续生成账单”开启；“开启提醒”默认关闭，邮件、Bark 和提醒中心均不提示。
4. 选择记账方式并保存。

| 记账方式 | 每月行为 | 消费统计 |
| --- | --- | --- |
| 自动记账关闭（默认） | 生成待确认账单 | 在流水核对实际金额并确认付款后计入 |
| 主动开启自动记账 | 按登记金额和锁定汇率生成已支付记录，来源标明自动记账 | 按账单日计入该月；不代表已经核实运营商扣款 |

新建时如果本期账单日已经发生，会生成本期账单；所填日期更早则逐月补齐，未来账单不会提前生成。想从本月开始统计，就填写本月账单日。每月 31 日遇短月取该月最后一天，之后回到原账单日。

关闭提醒不影响账单生成。提前 0 天表示账单日当天提醒，不等于关闭。独立提醒开关同样适用于普通会员订阅。新导出的日历不含闹钟；已经导入手机日历的旧提醒需在日历里更新。

## 修改金额与核对

卡片展示每月预算、账单日、下次账单及记账方式；首页可按“会员订阅 / 固定支出”筛选。固定支出计入预算，不进入会员到期倒计时和临期分布。

修改登记金额、套餐或分类只作用于后续新生成的账单，已经生成的账单保留当时快照。待确认账单可在“流水 → 确认付款”里填写本期实际金额，例如月租 58 元、本月额外费用 2 元，可确认实际 60 元。

开启/关闭自动记账不会批量修改旧账单。自动记账金额有误时，在流水先作废，再用历史补录填写正确金额；作废后后台不会为同一账期重新自动入账。更正付款日期保留原金额与汇率。

外币固定支出的自动记账使用登记的锁定汇率；调整汇率只影响以后新生成的账单。汇率尚未补全时保留待确认，不能按占位值自动计入消费。

## 暂停、恢复与停机

关闭“持续生成账单”即暂停，已有记录保留。恢复后从当前所在账期继续，跳过暂停期间；如果需要记录暂停期间的实际付款，可单独补录。

后台停机但记录仍保持启用时，恢复后补齐遗漏的每月账单，每期只生成一次；重启和重复扫描不会重复记账。每次每条记录最多推进 120 期，特别久的历史由后续扫描继续。

删除记录仍保留付款流水。停止服务可优先暂停；测试数据如已计入消费，应先作废测试付款再删除记录。

## 升级与备份

当前版本使用 SQLite v11 和业务 JSON v5。旧订阅迁移后保留会员类型和原提醒行为，自动记账关闭。新版仍接受 v1–v4 备份；v5 还保留手机号码及费用关联。

升级前按 [维护说明](OPERATIONS.md) 做在线备份。旧程序不能读取 v11 数据库，回退需使用升级前备份与旧版本源码/镜像。

多号码、年包和一次性手机费用请使用[按号码管理手机话费](PHONE_ACCOUNTS.md)。已有月租可直接关联到号码，保留流水。
